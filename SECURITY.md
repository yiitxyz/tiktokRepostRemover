# Security policy

## Supported version

Security fixes are applied to the latest release.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/yiitxyz/tiktok-repost-remover/security/advisories/new). Do not open a public issue for vulnerabilities and never attach TikTok cookies, `secUid` values, authentication headers, or exported account data.

This project has no server and does not collect credentials. Reports involving unexpected permissions, secret leakage, unsafe request replay, or destructive-selection bugs are especially useful.
